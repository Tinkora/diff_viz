# Support

`diff_viz` is a static, local-first tool. Before requesting help, run the
documented checks and capture the exact failing command, tool versions,
operating system, browser, and smallest reproduction.

Use [GitHub Discussions](https://github.com/Tinkora/diff_viz/discussions) for
usage questions and the issue tracker for reproducible defects. Never post
credentials, secrets, private input, or vulnerability details; follow
`SECURITY.md` for security reports.
