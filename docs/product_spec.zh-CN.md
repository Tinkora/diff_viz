# diff_viz 产品规格

## 产品一句话

一个浏览器原生的文本/代码差异可视化工具，支持并排和统一差异视图、JSON 语义差异、统一差异补丁生成与应用——全部在 WASM 中运行。

## 目标用户

- 需要在浏览器中快速比对文本、代码或 JSON 的开发者。
- 需要生成和审查 diff 补丁的代码审查者。
- 希望通过 Agent 调用 diff 能力进行自动比对的场景。

## 核心体验

1. 用户打开页面，在左右两个文本区域粘贴或输入文本。
2. 选择差异粒度：按行、按词、按字符。
3. 选择视图模式：并排视图或统一视图。
4. 点击对比，WASM 计算差异并渲染结果。
5. 结果以颜色编码显示：绿色（新增）、红色（删除）、黄色（修改）。
6. 可生成并导出统一差异补丁。
7. 可将补丁应用到原始文本以重建修改后文本。
8. JSON 模式：语义化比较键值对，展示变化路径和值。

## 技术架构

- **核心算法**：使用 `similar` crate（Rust）进行高性能文本差异计算。
- **WASM 桥接**：通过 `wasm-bindgen` 将核心 API 暴露给 JavaScript。
- **UI 渲染**：纯 HTML/CSS/JS，暗色主题，默认英文并提供中文入口。
- **零后端**：所有计算在浏览器中完成，无需服务器。

## API

### WASM 导出函数

| 函数 | 描述 |
|------|------|
| `wasm_compute_diff(left, right, mode)` | 计算差异，返回 DiffLine 数组的 JSON |
| `wasm_generate_unified_diff(left, right, left_label, right_label, context_lines)` | 生成统一差异补丁字符串 |
| `wasm_apply_patch(original, patch)` | 应用补丁，返回修改后文本 |
| `wasm_json_diff(left, right)` | JSON 语义差异比较 |

### 差异模式

- `lines` — 按行比较（默认）
- `words` — 按词比较
- `chars` — 按字符比较

### 视图模式

- `unified` — 统一差异视图（类 `diff -u`）
- `side_by_side` — 并排视图

## MVP 范围

- 两个文本输入区域（原始 / 修改后）
- 从剪贴板粘贴按钮
- 三种差异粒度：行 / 词 / 字符
- 两种视图模式：统一 / 并排
- 颜色编码结果展示
- 行号显示
- 生成并下载统一差异补丁
- JSON 语义差异（变化路径和值）
- 应用补丁功能
- 所有处理在 WASM 中完成

## 非目标

- 不提供 Git 集成
- 不提供语法高亮（代码语言的 token 级别）
- 不提供图像差异对比
- 不提供二进制文件差异
- 不提供协作编辑

## 验收标准

- 行级差异能稳定识别新增、删除、修改和未变内容
- 统一补丁可被标准 `patch` 工具应用
- JSON 语义差异正确识别键值变化（而非文本位置变化）
- 所有操作在 100KB 输入内 < 1 秒完成
- 纯浏览器运行，无网络请求
