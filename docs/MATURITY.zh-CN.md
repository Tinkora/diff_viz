# 成熟度证据

[English](MATURITY.md)

当前阶段：**Alpha**（`v0.1.0`）。

## 已有证据

- 核心解析和分析有面向结果的 Rust 测试。
- 编译后的 WASM 边界已在 Chromium 中验证。
- 浏览器主流程已覆盖四种视口宽度。
- 已配置严格格式化、Clippy、依赖策略和漏洞检查。
- 公开声明已经收敛为可实现、可复现的行为。
- 仓库已在 `Tinkora/diff_viz` 发布，拥有干净项目历史和不可变的 `v0.1.0` release。
- 已配置 Hosted quality workflow、CodeQL、依赖策略、私密漏洞报告和公开 Pages 预览，并由仓库规则要求执行。

## 进入 Alpha 前必须完成

- 记录至少一次使用真实 diff 的外部或维护者工作流。

## 进入 Beta 前必须完成

- 与实现工作之外的用户至少完成一次反馈闭环。
- 通过多个版本证明持续维护能力。
- 根据真实需求决定语言感知高亮、脱敏或其他格式是否值得长期维护。
